# Security Policy

Do not open a public issue containing credentials, private camera endpoints, participant data, or a reproducible path to an unauthorized third-party system.

For internal deployments, report security-sensitive findings privately to the repository owner. Rotate any credential that was accidentally committed and purge it from history before continuing work.

The core project intentionally avoids vendor-specific surveillance endpoints and external-system credentials. Keep that boundary intact unless a separate, explicitly authorized integration is reviewed.
