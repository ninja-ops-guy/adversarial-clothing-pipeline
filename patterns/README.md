# Pattern registry

Each production candidate receives a stable directory, for example `patterns/RAC-PER-0017/`, containing its manifest and references to immutable master artwork.

A pattern may advance only through RAC-D0 → RAC-D1 → RAC-D2 → RAC-P1 → RAC-P2 → RAC-M1 → RAC-M2. Digital evidence can never satisfy a physical or manufacturing state.
